# NextRole v1.0.0 검증 기록

검증일: 2026-09-27. 서비스의 합성 경력·직무 데이터와 별도 테스트 PostgreSQL을 사용했습니다. 운영 계정이나 외부 사업자의 실제 인증키를 사용하지 않았습니다.

## 자동 검증

| 범위 | 확인 내용 |
| --- | --- |
| Go 테스트·정적 검사 | `go test -race ./...`, `go vet ./...` |
| 점수 엔진 | 역량 정규화, 신뢰 상태, 점수 범위·근거, What-if 상승, ROI·경유 경로, 반입 직무 |
| 인증·권한 | 사용자 데이터 격리, 세션·API 키 권한, 회전·폐기, 관리자 접근, 암호화 설정 |
| OIDC/OAuth | 로컬 IdP의 실제 서명·JWKS 검증, issuer·audience·nonce·만료·state 재사용 차단, 이메일 충돌 |
| AI 스트리밍 | 로컬 호환 서버 SSE, 정상 종료·중단·오류·잘린 응답, 토큰 설정 검증 |
| 연동 | JSON/XML/CSV 매핑, 중복 ID의 원자적 거부, 읽기 전용 PostgreSQL 트랜잭션, 제한 시간 |
| 승인 | 기본 비활성, 소유권, 자기 승인 금지, 대기 상태에서 단일 결정, 저장된 검토 대상 |
| 이력서 | TXT·DOCX·PDF 추출, 크기·형식 제한, 텍스트 없는 PDF 안내 |
| 실제 채용 집계 | 합성 데이터 제외, 유효 기간·URL 중복, 지역·역량 빈도, 날짜별 비교 기준 |
| 브라우저 | 로그인·경력 저장·점수 변경·저장·메뉴 새로고침, 모바일 메뉴, 키 발급·회전·폐기의 실제 API 응답, 이력서 업로드·스트리밍 |
| 의존성 | 배포용 Go 1.26.8로 `govulncheck ./...` 실행: 호출 경로에 영향을 주는 취약점 0건. `npm audit --omit=dev`: 보고된 취약점 0건 |

GitHub Actions는 PostgreSQL을 포함한 Go 테스트, React 빌드, Chromium 브라우저 테스트와 Docker 실행 검증을 다시 수행합니다. 실행별 결과와 로그는 [CI 실행 목록](https://github.com/hkjang/nextRole/actions/workflows/ci.yml)에서 확인할 수 있습니다.

## 화면·문서 검증

- 로그인과 사용자·관리자 21개 경로를 데스크톱 1440×1050 및 모바일 390×844에서 캡처했습니다. 총 44개 화면에 프로필 메뉴 화면을 추가했습니다.
- 최종 캡처에서 JavaScript 오류와 페이지 가로 넘침은 없었습니다. [캡처 기록](screenshots/capture-report.json), [전체 화면](screenshots/).
- 모바일 API 키 표는 표 내부에서 가로 스크롤하며, 권한 배지와 관리 버튼을 모두 표시합니다.
- 사용자·관리자 가이드 PDF의 한글 텍스트 추출과 실제 렌더링을 확인했습니다. 긴 화면은 인쇄용으로 나누어 표시합니다.
- 홍보 페이지는 로컬 한국어 폰트를 사용하며 320·390·768·820·1024·1440px 폭을 확인했습니다.

## 오프라인 이미지 검증

`scripts/smoke-image.sh`는 Docker의 `--internal` 네트워크에서 서비스와 테스트 DB를 실행합니다. 로그인, 오프라인 경력 파싱, 프로필 저장, 점수 계산, 메뉴 URL 새로고침, 정적 리소스, UID 10001 실행 및 PDF 추출 도구를 검사합니다.

[릴리스 워크플로](https://github.com/hkjang/nextRole/actions/workflows/release.yml)는 이 검사를 통과한 서비스 이미지 **하나만** `nextrole-v1.0.0.tar.gz`로 저장합니다. PostgreSQL 이미지와 영상·문서는 이 압축 파일에 포함하지 않습니다. 해시와 실행 이미지 ID는 [릴리스 본문](https://github.com/hkjang/nextRole/releases/tag/v1.0.0)에 기록합니다.

## 배포 환경에서 확인할 항목

외부 Google·LinkedIn·Kakao·Naver·고용24 계정의 실제 키는 제공되지 않았으므로 실계정 연결 성공을 주장하지 않습니다. 관리자가 해당 공급자의 앱·동의 항목·callback URL·인증키와 네트워크 접근을 설정한 뒤 확인해야 합니다. 내부 Keycloak·AI 서버도 운영 URL과 모델의 문맥·출력 한도에 맞춰 연결 테스트를 수행하세요.

기본 데이터는 출처가 표시된 합성 시연 자료입니다. 실제 채용·훈련 데이터가 필요한 경우 관리자 연동 또는 반입이 필요합니다. 적합도·기간·비용은 계산 근거가 있는 참고값이며 취업 확률이나 보장된 결과가 아닙니다.

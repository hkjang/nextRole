# NextRole v1.1.0 검증 기록

검증일: 2026-09-27. 합성 경력·직무 데이터, 공식 규격에 맞춘 모의 공공 API 응답, 별도 테스트 PostgreSQL을 사용했습니다. 운영 계정이나 고용24의 실제 승인 인증키를 사용하지 않았습니다.

## 백엔드 검증

`go test -race ./...`와 실제 PostgreSQL 통합 테스트를 통과했습니다. 주요 검증 범위는 다음과 같습니다.

| 범위 | 확인 내용 |
| --- | --- |
| 점수 엔진 | 역량 정규화·신뢰 상태·점수 범위·What-if·ROI·경유 경로, 가공 매핑의 별칭과 미제공 경력·학력 기준 처리 |
| 고용24 4종 | XML 직업 요약·채용·훈련, JSON NCS 이름별 객체, 정상·오류 모의 응답, 필수 조회 조건·페이지·날짜 제한 |
| 원천 선택 | 필수 필드 유지, 선택하지 않은 원문 제외, 중첩 공식 필드 투영, 중단된 필드 제외, 출처 메타데이터 보존 |
| 저장·매핑 | 원천/가공 분리, 초안 격리, 게시 버전, 별칭, 동시 수정 409, 이력, 원천 내용 변경·삭제 시 계산 제외 |
| 코드 체계 | 직업코드와 채용 직종코드 분리, 검토한 채용 코드와 NCS 세분류코드의 정확 일치 |
| 경력 동의 | 안내 버전·본문 해시, 명시 동의, 변경 후 재동의, 경력 API·MCP 전처리, 철회와 동시 저장 잠금, 삭제 범위 |
| 식별정보 | 분석용 이름 제외, 이메일·전화·주민등록번호·표시 줄 제거, 사용자 입력 출처 구분 |
| 시장 데이터 | 합성·마감·중복 공고 제외, 과거 추론 역량 제외, 확인된 역량만 빈도 계산, v2 스냅샷과 비교 기준 |
| 인증·권한 | 사용자 격리, API 키 권한·회전·폐기, 관리자 접근, 암호화 설정, 로컬 OIDC/OAuth IdP 검증 |
| AI·파일·승인 | 모의 AI SSE 정상·중단·오류 처리, TXT·DOCX·PDF 추출 제한, 선택적 승인과 소유권 검사 |

공식 API의 실제 응답을 받았다고 주장하지 않습니다. [공식 데이터 항목과 활용 계획](work24-data-plan.md), [연동 설정](integrations.md), [테스트 소스](https://github.com/hkjang/nextRole/tree/main/internal)에서 계약과 구현 범위를 확인할 수 있습니다.

GitHub Actions는 PostgreSQL 포함 Go 테스트, React 빌드, Chromium 브라우저 테스트와 Docker 실행 검증을 수행합니다. 각 배포의 확정 결과는 [CI 실행 목록](https://github.com/hkjang/nextRole/actions/workflows/ci.yml)과 해당 커밋의 결과를 확인하세요. 진행 중인 실행을 통과 결과로 간주하지 않습니다.

## 화면·문서 검증

서비스 화면과 문서 이미지는 실제 서비스의 합성 시연 자료입니다. 데스크톱 1440×1050·모바일 390×844에서 로그인 포함 26개 서비스 화면을 촬영했습니다. 총 52개 기본 화면과 프로필 메뉴 1개를 포함하며 최종 캡처 기록의 오류는 0건입니다. 최신 화면 파일·크기·오류 기록은 [캡처 기록](screenshots/capture-report.json)과 [화면 갤러리](screenshots/)에서 확인합니다. v1.1.0에서 개인정보·동의, 원천·가공 데이터, 역량 매핑 검토, 개인정보 안내의 네 화면이 추가되었습니다.

홍보 페이지·사용자 가이드·관리자 가이드 HTML은 320·390·1440px 폭의 총 9개 레이아웃에서 가로 넘침과 JavaScript 오류 없이 표시됨을 확인했습니다. 가이드 HTML은 Markdown 원문에서 생성하며, 긴 화면은 PDF에서 읽기 쉽게 나누어 표시합니다. 원본 화면은 웹 가이드의 확대 링크로 제공합니다. 홍보 영상은 **v1.0.0 촬영본**을 보존하며 최신 공공데이터·동의 기능 안내는 v1.1.0 가이드에 있습니다.

## 오프라인 이미지 검증 절차

`scripts/smoke-image.sh`는 Docker의 `--internal` 네트워크에서 서비스와 테스트 DB를 실행합니다. 로그인, 현재 안내 동의, 오프라인 경력 파싱·저장·점수 계산, 메뉴 URL 새로고침, 정적 리소스, UID 10001 실행 및 PDF 추출 도구를 검사합니다. 실행 결과는 각 커밋의 CI 로그를 확인합니다.

[릴리스 워크플로](https://github.com/hkjang/nextRole/actions/workflows/release.yml)는 검사를 통과한 서비스 이미지 하나를 `nextrole:v1.1.0` 태그로 만들고 **서비스 이미지 하나만** `nextrole-v1.1.0.tar.gz`에 저장합니다. PostgreSQL 이미지와 영상·문서는 릴리스 첨부 파일에 포함하지 않습니다. 해시와 실행 이미지 ID는 [릴리스 본문](https://github.com/hkjang/nextRole/releases/tag/v1.1.0)에 기록합니다.

## 운영 환경에서 확인할 항목

외부 Google·LinkedIn·Kakao·Naver·고용24의 실제 계정 키는 제공되지 않았으므로 실계정 연결 성공을 주장하지 않습니다. 관리자는 공급자의 앱·동의 항목·callback·인증키·네트워크 접근을 설정한 뒤 실제 연결 결과와 수집 원문을 확인합니다. 내부 Keycloak·AI 서버도 운영 URL과 모델 한도에 맞춰 테스트합니다.

식별정보 자동 제외는 알려진 형식에 대한 처리이며 모든 자연어 개인정보를 제거하는 익명화 보장이 아닙니다. 저장 전 이용자 확인과 조직의 백업·보관 정책이 필요합니다. 적합도·기간·비용과 검토한 내부 역량 수준은 공식 취업 확률·정부 평가·확정 교육비가 아닙니다.

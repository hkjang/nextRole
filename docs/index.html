CLARITY BEFORE CONFIDENCE

좋은 선택은,
근거를 아는 것부터.

점수는 가능성을 탐색하는 참고 자료

적합도는 채용 성공 확률이 아닙니다. 규칙에 따른 비교 점수이며, 학습 기간과 비용 역시 입력과 가정에 따라 달라집니다.

합성 예시와 실제 데이터를 구분

기본 직무와 시연 공고에는 합성 출처를 표시합니다. 실제 공고와 훈련과정은 관리자가 승인된 데이터를 연결해야 제공됩니다.

공공 원문과 내부 수준을 구분

고용24 원천을 곧바로 공식 점수로 해석하지 않습니다. 요구 수준과 가중치는 관리자가 근거를 검토하고 게시한 내부 모델입니다.

동의하고, 확인하고, 직접 삭제

경력 분석 전에 안내를 확인합니다. 식별정보 자동 제외 후 결과를 직접 점검하고, 동의 철회로 저장한 경력 자료를 삭제할 수 있습니다.

AI의 설명과 계산 근거를 함께

적합도는 구조화된 데이터와 로컬 계산 엔진으로 산정합니다. AI 설명은 스트리밍으로 제공하며 외부 AI 없이도 핵심 기능을 사용할 수 있습니다.

GOOD QUESTIONS, CLEAR ANSWERS

궁금한 점을 먼저 확인하세요.

NextRole은 어떤 서비스인가요?

NextRole은 현재 경력과 목표 직무의 역량을 비교하고, 역량을 추가로 습득했을 때 점수와 경로가 어떻게 바뀌는지 실험하는 경력전환 의사결정 지원 서비스입니다.

인터넷이 없는 오프라인망에서도 사용할 수 있나요?

서비스 Docker 이미지와 PostgreSQL을 내부망에 준비하면 로컬 경력 분석과 시뮬레이션을 사용할 수 있습니다. 외부 AI는 필수가 아니며, 사내 OIDC와 OpenAI 호환 AI 서버를 연결할 수 있습니다. 인터넷 SSO와 외부 API는 해당 네트워크에 접근할 수 있어야 합니다.

적합도는 취업 성공 확률인가요?

아닙니다. 기술역량, 전이 가능 역량, 경력, 산업경험, 교육, 개인 선호의 규칙 기반 점수입니다. 학습 기간과 비용도 가정에 따른 참고 추정치이며 취업이나 급여를 보장하지 않습니다.

실제 고용24 채용공고를 바로 볼 수 있나요?

고용24 4종 프리셋을 제공하지만 실제 조회에는 승인된 인증키와 네트워크 연결이 필요합니다. 기본 직무·공고는 합성 예시입니다. 관리자가 선택한 원천 필드를 수집하고 검토한 매핑을 게시해 활용합니다. 개발 검증은 모의 응답으로 수행했으며 실제 승인 키 조회는 아직 검증하지 않았습니다.

경력 정보 동의를 철회하면 무엇이 삭제되나요?

본인의 경력 프로필, 저장한 시뮬레이션, 실행 기록, 선호와 본인 검토 요청을 삭제합니다. 계정과 개인 API 키는 유지됩니다. 식별정보 자동 제외는 완전한 익명화가 아니므로 입력·추출 결과를 직접 확인해야 합니다.

어떤 기술로 구성되어 있나요?

Go API, React·TypeScript·Mantine UI, PostgreSQL로 구성됩니다. 정적 웹 자산과 폰트가 서비스 이미지에 포함되며 운영 설정은 관리자 화면에서 관리합니다.

시작하려면 무엇을 준비해야 하나요?

Docker 실행 환경과 PostgreSQL, POSTGRES_DSN, BOOTSTRAP_ADMIN, BOOTSTRAP_ADMIN_PASSWORD, ENCRYPTION_KEY의 네 환경변수를 준비합니다. GitHub Releases에서 서비스 이미지 압축 파일을 받을 수 있습니다.
